# CSV ➔ DBF конвертер

Одностраничный Ruby CLI для конвертации `.csv` файлов в dBase III `.dbf`
(кодировка Windows-1251, целевой потребитель — 1С).

Интерфейс полностью интерактивный: меню, цветной вывод, журналирование и отчёты.

## Возможности

- Конвертация **всех** CSV из каталога `CSV/` одной командой.
- Конвертация **одного** файла по имени (ищется в `CSV/`) или по полному пути.
- Автоопределение кодировки исходника: BOM (UTF-8 / UTF-16LE / BE), UTF-8,
  UTF-16 без BOM и эвристика по однобайтовым Windows-1251 / KOI8-R / CP866.
- Всё транскодируется в UTF-8, а данные и имена полей DBF пишутся в **Windows-1251**
  (неподдерживаемые символы отбрасываются).
- Автопереименование при коллизиях (`_1`, `_2`, …).
- Журнал конвертаций с месячной архивацией и отчётом за 24 ч / 7 дней / 30 дней
  и за всё время.

## Требования

- Ruby (`>= 4.0`, см. `.ruby-version`).
- Только стандартная библиотека (`csv`, `date`, `fileutils`) — сторонние гемы не нужны.

## Запуск

```bash
ruby csv_to_dbf_converter.rb
```

Windows 11: запустите `run.bat` — он переключает консоль в UTF-8, проверяет наличие
Ruby в `PATH` и запускает скрипт.

### Неинтерактивный запуск

Скрипт блокируется на вводе после каждого действия и в конце, поэтому для пайпа
передайте всю последовательность, включая завершающий `Enter`:

```bash
printf '1\n\n3\n\n4\n\n' | ruby csv_to_dbf_converter.rb
```

При не-TTY выводе ANSI-цвета автоматически отключаются.

## Меню

```
1. Конвертировать все файлы
2. Конвертировать конкретный файл
3. Отчет
4. Завершить работу программы
```

## Каталоги

Все пути определяются относительно самого скрипта:

| Каталог / файл     | Назначение                                                        |
|--------------------|-------------------------------------------------------------------|
| `CSV/`             | Исходные `.csv`. Создаётся автоматически; пустой не удаляется.    |
| `DBF/`             | Сгенерированные `.dbf`.                                            |
| `Converted_CSV/`   | Успешно сконвертированные `.csv` **перемещаются** сюда.           |
| `conversion.log`   | Журнал (`epoch\tstatus\tимя\tdetail`), статусы `ok`/`skipped`/`error`. |
| `Logs/`            | Месячные архивы журнала (`conversion_<YYYY-MM>.log`).             |

Файлы без заголовков, пустые или упавшие при конвертации остаются в `CSV/`.

## Формат вывода

- DBF level 3 (маркер `0x03`), байт языкового драйвера `0xC9` (cp1251).
- Все поля типа `C` (строка). Ширина = максимальная длина значения в колонке,
  ограничена 1..254, значения дополняются пробелами.
- Имена полей — до 10 **байт**; пустые заголовки заменяются на `COL_<индекс>`.
- Запись оканчивается байтом `0x1A`.
